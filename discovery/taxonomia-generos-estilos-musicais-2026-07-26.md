Usada para desenhar o fluxo de classificação de músicas do app — ver também `musicas-por-genero-estilo-2026-07-26.csv`/`.json` na mesma pasta, com músicas representativas para cada entrada abaixo, e a memória `musica-taxonomia-classificacao-repertorio` para o próximo passo (classificar o repertório real do banco).

## Metodologia da amostragem

Esta pesquisa não lista todo gênero ou estilo já nomeado — isso seria infinito. O critério é **representatividade**: cada entrada aparece porque tem identidade própria (nome, público, contexto de uso) reconhecível, mesmo quando sua expressão mais famosa é uma ou duas músicas. Esses casos ficam marcados como **nicho**.

A organização segue tradições/raízes culturais (erudita ocidental, afro-diaspórica, latino-americana, brasileira, africana, do Oriente Médio, asiática, europeia não-anglófona, oceânica, eletrônica/experimental) — a ordem das seções não é hierárquica.

## Gênero × estilo: a diferença que estrutura esta taxonomia

Na prática do dia a dia os dois termos se confundem, mas cumprem papéis diferentes:

- **Gênero** responde "que tipo de música é essa, e para que serve socialmente". É a categoria ampla, ligada a função, contexto histórico e público — a unidade que aparece em prêmios, rádios, gravadoras e catálogos. Costuma ter nome estável e ecossistema próprio (artistas, casas, festivais).
- **Estilo** responde "como essa música em particular foi construída". É o tratamento sonoro específico dentro de um gênero (ou atravessando vários): instrumentação, técnica, andamento, produção, "escola" ou vertente. Costuma nascer de uma cena, época ou grupo de artistas, e por isso é mais fluido — muda de nome com mais frequência que o gênero que o abriga.

| Eixo | Gênero | Estilo |
|---|---|---|
| Exemplo | Samba, Rock, Jazz, Reggae | Samba de Breque, Shoegaze, Cool Jazz, Dub |
| Origem do nome | Consolidado por indústria/tradição | Cunhado por cena, crítica ou fãs |
| Estabilidade | Alta — muda em décadas | Baixa — muda em anos |
| Abrangência | Um "guarda-chuva" com vários estilos dentro | Pode atravessar mais de um gênero (ex.: lo-fi) |
| Uso típico | Filtro de catálogo, categoria de prêmio | Descrição de "clima"/sonoridade de uma música específica |

Zonas cinzentas existem — Bossa Nova é tratada aqui como gênero por ter ecossistema próprio, mesmo tendo nascido como um estilo dentro do Samba. A regra aplicada: quando o rótulo ganhou vida própria (artistas, disco, público que se identifica por ele), tratamos como gênero; quando vive dentro de/atravessando um gênero maior, tratamos como estilo.

## Aplicação no Musilista

O schema atual (`songs`, `repertoireSongs`, `groupSongs`, `importedSongs`) não tem hoje nenhum campo de gênero/estilo — é uma classificação nova. Duas rotas possíveis, na ordem em que valeria adotar:

**1. MVP — dois campos direto na música.** Segue a convenção já usada em `userProfiles` (`functions`, `instruments`, `competencies` como `text().array()`): sem tabela nova, sem join, só dois campos.

```
genero: text()                     // um valor — "Samba", "Rock", "Sertanejo"
estilos: text().array().default([]) // zero ou mais — ["Pagode"], ["Grunge", "Rock Alternativo"]
```

Isso já resolve o caso de uso mais provável do fluxo: filtrar/agrupar repertório por gênero na hora de montar um setlist, e opcionalmente refinar por estilo/clima. Suficiente enquanto a lista de valores aceitos vive no código (ex.: um enum/const em `apps/web`), curada a partir da taxonomia acima.

**2. Caminho de crescimento — tabelas normalizadas.** Vale migrar para cá se o Musilista precisar de: administração da taxonomia pela UI (sem deploy), estatísticas por gênero, ou permitir que grupos criem estilos próprios.

```
musicGenres  { id, name, family }               // "Rock" / família "rock"
musicStyles  { id, name, genreId (nullable) }    // "Grunge" -> genreId de "Rock"
songGenres   { songId, genreId }                 // N:N — uma música pode ter mais de um gênero
songStyles   { songId, styleId }                 // N:N — idem para estilo
```

`genreId` nullable em `musicStyles` porque alguns estilos atravessam gêneros (lo-fi, por exemplo) — nesse caso o estilo fica "solto" e é a música que carrega os dois vínculos.

**Onde a distinção gênero/estilo importa para o fluxo:** se o objetivo é filtro/busca de repertório, gênero sozinho já cobre boa parte do caso — é o nível que músicos reconhecem de cabeça. Estilo entra como refinamento opcional, útil sobretudo para casos como "quero só o bloco de pagode do repertório" ou "separar o forró pé-de-serra do piseiro" dentro de um mesmo evento.

## Limitações desta amostragem

Fronteiras entre gênero e estilo são contestadas mesmo na musicologia — a classificação acima é uma convenção prática para o produto, não uma tese acadêmica. Vários estilos marcados como "nicho" têm cenas inteiras por trás de um ou dois nomes famosos no Brasil; a amostra prioriza reconhecimento, não justiça histórica com cada cena. Novos gêneros/estilos devem ser adicionados seguindo o mesmo critério: um nome com identidade própria, mesmo que pequena.
